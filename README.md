# Qodvexa Technologies Portfolio

Static company portfolio with responsive layouts, light/dark themes, a 3D network globe, project filters, and section navigation.

## Preview locally

Run `python -m http.server 4173 --directory dist` and open http://localhost:4173.

## Deploy

Import this repository into Vercel. Framework: Other. Output directory: dist. No build command or dependencies are required. The root vercel.json sets the output directory.

## Content

- `dist/index.html`: page content
- `dist/style.css` and `dist/light.css`: theme styles
- `dist/app.js`: client projects and interactions
- `dist/showcase.js`: credited third-party references
- `dist/globe.js`: interactive globe
- `dist/assets/`: project screenshots, logo, and company PDF

Third-party product screenshots and names remain attributed to their respective creators. Reference cards are labeled separately from delivered client work. The software licenses linked on those cards do not grant ownership of third-party trademarks or websites.
